=== finding ===
THE CACHE AGREES WITH THE CHIP.

460 cacheable registers were read through the cache and again
with the cache bypassed, and every pair was identical. Because all
460 are preloaded from reg_defaults, that is simultaneously a
check of the cache and of the defaults table: a wrong reset value
would surface here as a mismatch against the live codec.

209 readable volatile registers were walked and excluded
from the comparison by the volatile predicate, so nothing in the
interrupt or status path was served from the cache.

What this does NOT cover: volatility of families this run has no
stimulus for. Digital gain, clip-detect, VBAT and the IIR/ANC
windows are marked volatile on downstream's authority, not on
measurement here, and a register wrongly marked volatile costs
only a hardware read. The dangerous direction -- cacheable when it
should not be -- is what this run measures, and only for state the
codec reached on this boot.
